# BFGI Alumni Portal (Next.js)

## Overview

The BFGI Alumni Portal is the official public web presence for Baba Farid Group of Institutions alumni relations. It serves as an institutional showcase, alumni directory, event ticketing hub, media gallery, and student support center.

---

## Key Features

- **Institutional Landing**: Dynamic statistics, distinguished alumni spotlights, and leadership vision.
- **Global Alumni Map**: Searchable alumni directory with interactive geographic distribution powered by Leaflet.
- **Event Discovery & RSVP**: Browse offline and online campus events with automated registration limits.
- **Media Gallery**: High-resolution event memories and departmental photo albums.
- **Student Helpdesk**: Direct contact and inquiry submission into the administrative ticketing system.

---

## Technical Stack

- **Framework**: Next.js 16 (App Router), React 19
- **Styling**: Tailwind CSS v4, PostCSS, Radix UI
- **Mapping**: Leaflet, React Leaflet, React Leaflet Cluster
- **State & Networking**: Zustand, Axios

---

## Development Setup

```bash
# Install dependencies
pnpm install

# Start development server on port 3000
pnpm dev

# Build production bundle
pnpm build

# Start production server
pnpm start
```
