# BFGI Admin Portal

## Overview

The BFGI Admin Portal is the administrative management interface for the Baba Farid Group of Institutions alumni ecosystem. It enables staff, moderators, and system administrators to oversee user verification, manage campus events, curate photo albums, resolve helpdesk tickets, and analyze engagement metrics.

---

## Key Features

- **Dashboard & Analytics**: Real-time visual metrics on user growth, event participation, and ticket resolution.
- **User Moderation**: Student and alumni verification via ID card and degree validation, role assignments, and developer designations.
- **Event Management**: Create and configure campus events, track registrations, and export attendee rosters.
- **Gallery Uploads**: Create albums and batch-upload high-resolution media with Cloudinary integration.
- **Support Helpdesk**: Track, prioritize, and resolve student and alumni support tickets.
- **AI Assistant**: Google Gemini-powered administrative assistant for campus queries.

---

## Technical Stack

- **Framework**: React 19, TypeScript, Vite
- **Styling**: Tailwind CSS, Lucide Icons, Radix UI
- **Charts**: Recharts
- **State**: Zustand
- **Routing**: React Router DOM v6

---

## Development Setup

```bash
# Install dependencies
pnpm install

# Start development server on port 5174
pnpm dev

# Build production bundle
pnpm build
```
